Scope of practice — read first

Only test applications you own or have explicit written authorization to test. Unauthorized testing of third-party systems is illegal under the Computer Fraud and Abuse Act (US) and equivalent computer-misuse laws worldwide. Every lab, payload, and technique in this course is meant for your own local environment, PortSwigger Web Security Academy, or a signed engagement — never a live site you stumbled onto.

Why BSCP

The Burp Suite Certified Practitioner (BSCP) is PortSwigger's own official, fully practical certification — timed and hands-on against realistic vulnerable applications, requiring you to actually chain and exploit vulnerabilities rather than answer questions about them. It's valid for five years and maps directly onto the Web Security Academy's topic list, which is why every module in this course cites the matching Academy topic. Stage 4 · Module 2 has the full objective-to-module mapping table.

How to use this course

  1. Work the stages in order — each assumes the previous stage's tools and vocabulary. Just open the next burp-course-*.html file in your browser when you're done with one.
  2. Don't skip the labs. Reading about SQL injection and finding it yourself in a real request are different skills; the exam and real engagements only test the second one.
  3. Every module ends with a knowledge check, flashcards, and/or interview questions — use them as a recall gate before moving on, not just a read-through.
  4. Keep a running lab notebook (a plain text file is fine) of every finding you produce, from Stage 1 onward — by Stage 3's mini-project you'll be turning that notebook into a real report.
  5. Re-take the self-assessment rubric in Stage 4 honestly before booking the real exam.

Recommended lab environments

  • PortSwigger Web Security Academy — free, browser-based, purpose-built labs for every topic in this course, organized by exactly the difficulty tiers (Apprentice/Practitioner/Expert) this course references. The primary environment for Stages 1–4.
  • OWASP Juice Shop — a modern, deliberately vulnerable web app you run locally; excellent for open-ended, self-directed hunting between structured labs.
  • DVWA (Damn Vulnerable Web Application) — classic PHP/MySQL vulnerable app with adjustable difficulty, good for early SQLi/XSS repetition.
  • WebGoat — OWASP's guided lesson-style vulnerable app, useful as a second angle on the same OWASP Top 10 categories.
  • Bug bounty platforms (once you're Stage 3+) — legal, authorized real-world targets with defined scope, the natural next step after this course for continued practice.

Course-wide checklist

  • Burp Suite installed (Community to start; Professional by Stage 2 for realistic Scanner/Sequencer/Turbo Intruder work)
  • CA certificate installed and HTTPS interception verified
  • A local vulnerable-app environment running (Juice Shop or DVWA) alongside Academy labs
  • A lab notebook or notes file started from day one
  • Written authorization or a purely local/legal target for every single test you run, no exceptions
